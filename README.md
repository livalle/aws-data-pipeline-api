# aws-data-pipeline-api
Data pipeline using AWS S3, Glue, Athena and Airflow to ingest and analyze API data

# AWS Data Pipeline Project

This project demonstrates a simple data pipeline built on AWS.

## Architecture

API → S3 → AWS Glue → Athena → Analytics

## Technologies

- AWS S3
- AWS Glue
- Amazon Athena
- Apache Airflow
- Python
- SQL

## Pipeline Steps

1. Data ingestion from public API
2. Storage in S3 Data Lake
3. Transformation using Glue
4. Query using Athena
